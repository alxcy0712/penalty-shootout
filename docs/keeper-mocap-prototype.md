- `npm run build` 和独立三页面 Vite 预览构建通过，保留既有 Three.js 大分块提示。
- 本机 macOS arm64、Codex 内置 Chromium 浏览器、1280×720 视口、渲染区 1280×576、渲染 DPR 1.70、抗锯齿、无阴影。O05E 单次约 1 秒原速播放：帧时间中位 16.7 ms / P95 18.0 ms；动画均值约 0.07 ms；开发服务器本地 GLB 加载+解析约 39–54 ms，含缓存影响。短时样本仅作为初测，尚无同条件程序门将性能对照。
- 浏览器复核了扑救的起始、腾空、伸臂、末段，以及抱球/热身/起身/预备/判断错误关键姿态；扑救检查了正常和四分之一速度。390×844 与 844×390 模拟布局检查通过，修复横扑出画。浏览器错误日志为空。

## 待验收与限制

- 研究数据为多机位无标记重建，有遮挡误差；两段短片缺少足球轨迹和完整起身。当前新动捕仅用于预览，尚未与正式比赛的触球/接球事件绑定。
- 其他菜单项仍沿用现有程序动作；手腕包球、脚掌承重、落地撑手及动作中断衔接需要后续专门打磨。全身穿模、所有动作全程原速/慢速人工验收尚未完成。
- 原研究骨段与人物骨段不同，统一骨长和接地会调整根节点高度；脚底锁定及滑动距离尚未全面量化。
- 中端手机真机稳定 60 fps、弱机 30 fps、长时间温升/降频、首次冷加载传输、GPU/内存及重复进入资源释放实测待验收。浏览器模拟数据仅用于布局和初步检查。

## 完整动作链迭代

- 新增左右两条实拍扑救 → 落地缓冲 → 程序起身 → 恢复预备链，保留原始短片段供对照。衔接 0.55 秒，继承末帧位置/旋转速度并衰减，五次缓入缓出；固定旋转半球，防止接近 180° 时插值路线翻转。关节局部位移维持四肢骨长。
- 动捕采样使用独立隐藏骨架，避免程序修改骨骼与 AnimationMixer 属性缓存相互影响。共享模型资源，隐藏骨架不绘制；退出回收 mixer。
- 按骨骼分组的网格极值点用于落地高度修正，避免逐帧扫描全部顶点。全网格回归采样测得最低点：左 -17.5 mm、右 -12.2 mm（仍有轻微穿地，待继续打磨）；最大 120 Hz 关节步长约 10.4 / 7.0 cm。尚未完成足底锁定和完整自碰撞检查。
- 新增实际接球 → 缓冲 → 抱球回放，直接记录现有 Shot 固定步物理。左右均发生 saved/caught，接触约 0.3667 秒；按现有 HOLD_DURATION 收球，抱稳后球心与 grip.center 一致。没有将无足球轨迹的研究动捕强行绑定为实际碰撞轨迹。
- 回放时间轴支持前后拖动且确定性一致；这项检查覆盖播放/暂停/跳转。比赛动作中途切换、提前/延迟输入的全套新动画衔接仍待接入。
- 修复模型运动后被静态蒙皮包围体误裁剪的问题：单角色预览关闭该模型的视锥裁剪，正式比赛集成需单独确定动态包围体。

本轮动作链在 JavaScript 中衔接，`keeper-prototype.blend` 仍保留两个原始烘焙片段；新增起身链尚未另行烘焙为 Blender Action。正式比赛继续使用原实现。

本轮验证：132/132 测试通过，正式构建及三页面预览构建通过。桌面 Codex 内置浏览器 697×784、渲染区 697×557、渲染 DPR 1.70，左侧完整链原速约 3.87 秒样本：帧中位数 16.7 ms / P95 17.6 ms，动画均值约 0.19 ms。检查了左侧原速收势、右侧慢速衔接和实际持球关键帧；真机及全量动作验收仍待进行。
