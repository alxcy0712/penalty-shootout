# A2 二次开发：状态与测量契约

设计入口：[ADR](architecture/ADR_A2_RUNTIME_RELIABILITY.md)。本阶段保留A1的输入和存档契约，物理、模型和捕获片段不作改动。

## 图形中断

`graphics-lifecycle.js`只管理应用许可；Three r180仍管理底层上下文资源。状态为ready→lost→restoring→restored→ready；超时或绘制异常为failed。浏览器restored回调到来后，在冻结的比赛状态上成功调用一次绘制，才显示继续按钮。这个返回只证明调用没有抛异常，不能证明驱动/GPU或画面像素完全正确。

`main.js`合并用户暂停、页面隐藏/离开、加载和图形锁。图形锁不修改用户暂停，Close也不能解除图形锁。恢复重置时钟基准，不把中断时长补入比赛；原累积的不足一个物理步保留。lost立即取消指针并保存当前进度，保存失败仍使用A1提示。仅有一个rAF循环；没有在恢复回调中再启动循环。

恢复等待15秒只改变提示，不表示恢复一定失败或浏览器已放弃。迟到的真正restored事件仍可进入重绘。失败刷新属于用户操作，不能用强制创建更多renderer“重试”。未来新增页面/模式应共用runtimeBlocked，不单独绕过输入门禁。当前main只初始化一次Stadium和事件控制器，资源重试不重建它们；初始化函数不是可重复挂载API。若以后引入SPA挂卸载，宿主需保存并调用订阅取消函数、graphics.dispose和actor.dispose，并停止自己拥有的唯一RAF，不能只重复调用初始化。

[Khronos规范](https://registry.khronos.org/webgl/extensions/WEBGL_lose_context/)说明恢复调用是异步，必须等待事件，lost须preventDefault才允许恢复。实际设备验收可使用该扩展，但本轮Node事件故障注入不等于真WebGL驱动测试。

## 人物加载与所有权

角色公开不可变assetStatus、subscribeAssets(listener)和retryAssets()；ready仍兼容旧Promise接口。加载期阻止开始/继续下一脚，失败后程序角色可用并明确降级提示；重试只在home/ready/result/finish边界，避免飞行中替换身体。可选紧凑动作失败也必须报告。程序角色是已有功能回退，不能把正式GLB的逐三角形验收等同于简化模型也有完全相同的视觉碰撞精度。

缓存持有源几何/纹理，角色租用它们；角色拥有材质/骨架及用于辅助骨和手指变形的克隆。迟到超时结果不得覆盖新一代，实例销毁不得释放别人的源资源。准备新根成功后才替换旧根。新资产类型必须声明共享、克隆、销毁责任，不能随意遍历整个scene并dispose所有对象。新扩展优先注入assetCache或fallbackFactory，保留load直接覆盖仅为旧集成兼容；任意子类自建资源仍须声明所有权。旧覆盖在构造失败时恢复回退，调用super成功后又失败时也不能恢复已经释放的旧绑定。默认加载器的15秒期限/两个未完成工作上限不能约束旧子类自己发起的任意IO；新扩展应迁移到缓存注入接口以继承这些保障。

Three官方[GLTFLoader文档](https://threejs.org/docs/pages/GLTFLoader.html)特别提示ImageBitmap需要显式处理；不能把JS对象失去引用等同GPU和位图释放。请求使用私有LoadingManager尽力取消；每个URL至多两个尚未真正结束的工作，旧浏览器不支持取消或解码未返回时，再次重试显示忙碌，不继续堆积请求。网络请求的超时不能强制中断同步解码/主线程阻塞，也不能保证所有底层网络实现支持取消。

## 性能窗口

FrameProfile只在URL带profile时存在。rAF原始时间是帧间隔来源；物理限幅dt和renderer调用频率不能代替它。所有有限正前台间隔进入精确计数、均值、最大值和长帧计数。百分位使用固定2048桶（16KiB）的对数直方图，显示P95≤/P99≤上界；正常桶宽小于4.43%，没有声称精确分位。

隐藏、加载或图形中断、主动暂停按三类状态排除；profile中的“图形中断”包含应用为加载资源而挂起动画，具体原因由资源/恢复提示说明。跨状态间隔丢弃，不把后台空档归为前台卡顿。报告窗口不清除活跃时间基准，跨窗口长帧属于结束回调所在窗口。重复/倒退/非法时间另外计数。窗口至多每秒更新，即使暂停无绘制，也清除陈旧FPS。

CPU更新+提交计时覆盖Stadium.update到render返回，不是GPU耗时，也不是main全帧CPU。绘制计数包含阴影，但资源数量不是字节。“几何体a/b”的b沿用构造场景时的结构几何种类数，不是GPU预算或容量上限；异步人物加载后的上传数应看a。默认未开profile不分配直方图，不收集CPU计时。真机温度/网络/GPU测试仍是后续工作。

## 发布验收

使用`npm run qa:release:plan`检查固定计划，`npm run qa:release`执行完整验收。计划不是通过证明。固定清单包含669球、223实际接球，主皮肤/抱球/轨迹及可见手指/拇指变形均需收据；结果绑定输入、工具、脚本和源码hash。默认重检查串行，输出到仓库磁盘的新目录；禁止复用旧结果目录冒充新运行。

本入口验收当前正式运行时与固定资产，不是A1改模候选的自动提升适配器。A1的改动几何仍保持禁止提升，不能拿本轮绿色收据绑定另一份候选，也不能省去人工视觉审查。

扩展配方或资产必须显式升级清单并解释结果变化；不能绕过失败收据或把旧manifest默认路径当完整集合。节点测试、离线皮肤和构建通过仍不等同真机/真实浏览器验证。后续发布工具说明以`tools/qa/RELEASE_QA.md`为准。
