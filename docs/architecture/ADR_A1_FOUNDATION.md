# ADR：A1 输入、持久化与模型候选边界

状态：已实施，502项集成测试与构建通过，2026-10-03。基线研究分支 `40d1d72`；本次不扩展到 A2 图形恢复、加载器或性能档位。

## 目标与不变项

这次先修复校准尺度不一致、布局移动误射、保存状态不真实和制作脚本误覆盖风险，并让未来模式/设备/模型能通过明确接口扩展。成功标准不是文件数量或“全部测试绿”，而是用户意图、失败恢复和后续维护路径都可说明。不存在已经证明的“完美”；剩余设备和制作能力边界必须明确记录。

正式模型、动作、接触表和物理公式不随这次基础改造变化。旧射门配方/随机状态与比赛存档仍须可读；移动手指不带动球员、释放才助跑，原有暂停、多指和旧事件失效语义继续保留。

## 1. 输入分成意图映射与会话生命周期

纯校准模块定义版本化的每设备配置，不访问DOM或localStorage。新配置使用CSS像素的有效满力度行程，死区单列；同一物理CSS像素上划在校准和比赛得到同一力度。方向、球路高度与弧线仍按球场/视口坐标映射，不声称所有瞄准语义都与尺寸无关。

旧设备倍率无法反推出当初用户在什么高度校准。保留明确的legacy-height适配器，继续原公式，同时提示重新校准；只有明确保存新校准/恢复默认才转成新单位。不能把一个旧数字悄悄解释为像素。新默认参考原390×844布局的509px手势区，满行程378.48px；这只是兼容默认手感的起点，三次校准才记录用户舒适行程。

每个手势持有指针ID、所属元素、设备、校准快照和初始矩形。布局位置/尺寸改变则取消本次会话并清空预览；旧松手不能提交。不能在一条轨迹中混用不同局部坐标。会话模块只处理坐标和有效性，main负责提示、暂停和真正launch。

校准弹层使用草稿。保存仅提交当前设备；取消/关闭不能改变正式设置。设备切换的草稿处理必须在UI说明，不暗中覆盖另一个设备。未知设备/NaN/不合法版本在边界归一化。

## 2. 持久化返回结果，不隐藏在全局布尔值

小型存储适配器依赖注入Storage访问和序列化，返回可枚举状态：不存在、有效、格式/版本不兼容、读取失败、写入失败、成功。比赛和偏好各自记录状态；重试成功可以恢复，不用一次失败后永久为false的全局锁存器。

适配器不决定校准单位或比赛规则；main负责调用现有Match/Shot恢复与UI反馈。旧version1比赛结构保留，配置版本由校准模块负责。解析JSON成功不是业务状态有效，恢复异常须落到可理解的安全界面。

只有实际写入成功才能显示“已保存”。如果采用“仅本页保留”的提示，就必须保留可继续的会话快照，不能在Home清掉shot后又只读取旧磁盘数据。新建比赛替换未完成进度须明确确认；取消必须保留磁盘与会话快照。保存新局失败不能先删除旧存档。损坏/不支持的数据不因一次读取就自动删除。

## 3. 制作输入与发布资产不是同一概念

当前22骨可编辑.blend是发布GLB的重建副本，不携带完整制作历史/幂等标记；运行时另加2根肩部辅助骨。旧rebuild不能凭“能打开文件”推定可重建。预检必须在任何源文件写入前验证工具/API、输入种类、hash与脚本版本。

候选目录位于正式assets之外，清单固定文件集合和格式版本；只允许注册的固定操作，不执行清单提供的任意命令。输出包含输入/工具/参数/产物身份，校验后变动会令证明失效。结构通过不等于球体、地面、连续性或美术通过。

A1首先支持当前产物的安全快照、已制作候选导入/检查与明确的受限提升策略。尚无完整候选隔离深度验收的真实改模包不得凭外部“passed”字符串提升；保留这个能力缺口，后续接固定全几何门禁和人工视觉审阅后才能开放。正式资产本轮不重建。

多文件提升不是文件系统级原子操作。采用先备份、持久日志、逐项替换和可恢复回滚；回滚也检查当前hash，拒绝覆盖其他人后来的修改。测试必须模拟中间失败，而不只测成功复制。

## 4. 扩展规则

- 新设备/输入模式增加明确配置版本和纯映射，复用同一手势取消契约；不能直接往main加第二套功率公式
- 新存档字段保持版本迁移与缺省规则；持久化适配器不导入比赛物理，避免业务与浏览器API互相依赖
- 新模型制作适配器先固定工具/输入种类与候选输出，再证明生成/验收/提升各环节；不能绕过旧输入hash或直接覆盖发布文件
- 未来A2上下文恢复可复用暂停/失败状态，但不在本轮暗中加上图形资源框架

## 验证计划

先用原研究探针确认修复前行为，再增加新契约测试：同120px手势跨校准/比赛一致、不同布局取消无误射、草稿和设备隔离、旧配置保留、旧version1比赛恢复、存储失败/重试/Home继续/覆盖取消。接实际main事件harness，不只测试纯函数。

制作测试检查不支持版本/变化输入/异常路径在写正式文件前停止；清单/输出篡改失效；部分提升失败可恢复且不覆盖无关后续编辑。最后全测试/构建、正式资产/物理源hash检查和固定射门配方一致性。真实手机触摸/浏览器持久化仍须后续实机验证，不能用事件替身冒充。

## 审查后的修正

独立审查发现并修复了初版边界：游戏允许的短斜划不一定是有效校准样本，因此共用向上行程校验且第三次推导先成功再提交草稿；校准失焦/隐藏也必须取消拥有的指针。Home续玩通常从会话序列化快照恢复新Match/Shot，不能复用旧对象破坏历史归档隔离。只有最新序列化本身失败时才保留明确标注的原现场兜底。存档结构检查补齐跟踪脚步、犹豫姿态、展示缓存与power阶段lockedX依赖，在切入live前拒绝已知会造成下一帧异常的数据。

全套初版回归曾发现归档隔离失败；没有删掉原来的不同引用/旧归档不变断言。模型工具的prepare日志覆盖锁取得前的中断；回滚绑定工作区、原仓库和清单，仍不声称断电持久性或抵抗任意外部并发写入。

赋值边界采用版本化数据字段白名单，而不是不断添加方法名黑名单。未知v1字段拒绝并保留原数据；新字段开发必须更新明确的迁移/格式契约和669球schema兼容扫描。嵌套保留键迭代检查避免递归栈风险，恢复后的原型方法还有独立冲突检查。
