# 本轮基线与原型修正

分支：`codex/striker-prototype-refinement`。从已有 `codex/fifa14-character-motion` 分支携带未提交工作创建。原 `striker-prototype.blend/glb/json` 全部保留，Blender 中未保存的窗口未被覆盖。本轮导出为 `striker-prototype-refined.*`。没有提交、合并、发布或部署。

## 核实与优先级

已阅读 README、用户提供的 AGENTS 约束、anatomy/character/scene/engine、原型生成器及人物/规则/动作测试。原比赛共用 `anatomy.js` 骨架和碰撞胶囊、120 Hz 物理、渲染插值；视觉球仍取 `Shot` 模拟结果。GLB 是单独预览原型，尚未替换比赛骨架和门将碰撞。

- P0：GLB 烘焙的四元数相邻帧符号不连续，导致手部插值跳变；整段 240 Hz 采样发现 1.425 秒处异常。
- P1：朝向矩阵与 Blender 零 roll 静置骨骼不一致，导致躯干扭窄、接缝和鞋面转向异常。
- P1：袜子独立表面复用全腿参数，部分小腿顶点绑定到大腿；上肢网格与静置关节位置存在偏差。
- P1：躯干各段绑定位置与动作的髋部基准不一致，腰部/颈部可见分离；发际线遮住眼睛。
- P1：原型右脚偏离球心约 12.5 cm，号码只跟随根朝向，侧向球路在左右对比中镜像不一致。
- P2：横屏低高度时性能面板遮挡腿部；原型释放未显式释放 skeleton bone texture，GridHelper 几何未纳入清理。

## 本轮修正

统一静置骨骼的转轴与躯干关节高度，按真实肩/肘/腕位置生成上肢轮廓；袜子按解剖高度赋权；颈部延伸到领口内，调整发际线、手掌尺寸及布料/皮肤/鞋的粗糙度。去掉短裤中央多余的下缘环。

动画烘焙统一四元数半球并使用逐帧线性采样，消除符号翻转的插值突跳；触球阶段右脚向球心收拢、减小触球前减速。号码使用胸骨逆绑定矩阵附着；方向修正施加到胸部，使支撑脚保持固定。左右预览使用相同物理球路变换。

预览新增“修改前 GLB / 本轮修正”切换和可折叠性能数据。暂停按需绘制逻辑沿用原实现；后台停止、销毁时清理独立骨架纹理和网格资源，保留 BFCache 页实例。

## 验证与边界

基线 108 项测试通过；修正后 112 项通过。新增校验袜子权重归属/归一化、号码与皮肤变换一致、触球脚接近实际球、全片段关节连续性和反复拖动确定性。原有固定腿长、支撑脚锁定和接触段蒙皮包围盒检查通过。生产主页面构建通过（601.14 kB JS；既有 500 kB 分块提示）；原型也独立构建到临时目录验证，未改生产入口。

浏览器 Chrome 153 / macOS，本地 Vite，1200×739。初始基线 DPR 2，帧间隔 P50/P95 16.7/17.0 ms，44 次峰值绘制；修正后 DPR 1 的独立短窗口为 16.7/18.6 ms，42–44 次绘制，最大可见 54,572 三角面，单次动作更新约 0.2 ms。两次 DPR 不同，这些观察不能证明帧率提升。资源减少及消除插值突跳有代码/资产检查支撑。

修正后一次缓存加载约 46.6 ms、解码 4.8 ms，页面导航约 73 ms；这些是 localhost 热缓存数据，不能代表手机首次网络加载。27 组方向×力度×球路在浏览器完成触球点切换检查。正常速度、关键阶段截图及慢速用于本地复核；旧 motion-lab 全部 16 种门将动作保持原实现。

剩余验收：原型所有球路共用一条基础射门片段，方向/力度只做小幅胸部修正；完整差异化射门、门将扑救/接球/起身、与物理骨架全面对应、近景服装接缝和关节体积仍需后续阶段。真实手机首次加载、60/30 fps 档位、长时发热降频、GPU 时间与长时内存均待真机验证。

手机视口模拟 390×844、DPR 1 的一次完整片段采样 P50/P95 为 16.7/16.9 ms，>33.3 ms 为 0。844×390 横屏检查发现性能面板遮腿，已改为低高度时默认折叠，并保留数据按钮。


## 现成 CC0 人物候选已接入

免费 Standard 包实际包含 Superhero 男/女两种 FullBody（其余体型属于其他版本），随包许可已保存至 `assets/characters/quaternius-source/LICENSE.txt`。本次选择男性角色，原始 14,318 三角面、含 root 共 65 骨。保留原作者 glTF/bin/必要颜色贴图，转换脚本为 `tools/blender/create_quaternius_striker.py`。

将原网格按原权重转入项目静置骨架，合并手指到手掌（射手原型阶段），规范胸腹/肩/髋映射；切分平整的球衣、短裤、袜口边缘，补充球鞋鞋底和鞋带；重新计算静置姿态表面法线，保留面部贴图；去掉多余 UV 与顶点色。输出 `striker-quaternius.blend/glb/json`。

当前骨骼映射：`pelvis→pelvis`，`spine_01/02→spine`，`spine_03→chest`，`neck_01→neck`，`Head→head`；原角色正 X 的 `_l` 映射项目正 X 的 `.R`，负 X 对应 `.L`，以空间位置为准；`upperarm/lowerarm/hand→upper_arm/forearm/hand`，`thigh/calf/foot/ball→thigh/shin/foot/toe`。碰撞与球物理仍留在现有比赛实现，原型只验证视觉骨段和接触事件。

最终候选：17,518 三角面，22 骨，6 材质/6 个渲染网格；512² 皮肤和 128² 眼睛两张 JPEG；GLB 354,884 B（346.6 KiB），通过 18k 面、24 骨、6 材质、2 贴图、400k B 的单角色预算。号码另用 256×128 画布。

最终全套 121 项测试通过（两个原型共 16 项资产/动作检查）；生产主页面和独立原型构建均通过。浏览器正常速度及四分之一速度播放、关键阶段截图已检查。三次加载/绘制/释放 CC0 角色，每次 WebGL 计数均为加载后 7 几何/4 纹理，释放后 0/0（含号码和骨架纹理）；这证明本轮显式释放路径回收了这些 GPU 资源，不替代长期堆内存/真机热测试。
