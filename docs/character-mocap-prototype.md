# CMU 足球动捕单角色原型 · 2026-09-25

入口：`/motion-lab-prototype.html?asset=mocap`。左侧保留此前 Quaternius 程序动作，右侧播放真人动捕。两侧播放倍率相同，左侧起点偏移 0.05 秒使触球对齐。原比赛、球物理、规则、球队和存档代码保持原实现。

## 制作与来源

角色沿用此前的脸部、体型、缩小后的手掌、服装与号码。Blender 制作文件为 `assets/characters/striker-mocap.blend`，浏览器文件同名 GLB，事件和预算见同名 JSON。旧 Blender 文件保留。

动捕来自 CMU 10_01，经 Bruce Hahne/cgspeed Daz-friendly 转换，通过已记录提交的镜像取得。原始文件、校验和、许可、转换说明位于 `assets/characters/mocap/cmu-soccer/`。人物 CC0；动捕遵守 CMU 条款，允许商业项目使用，禁止单独转售数据。采集中的手指通道不作为真实手指动捕使用。

截取源片段 3.15–6.65 秒，保留原速，60 Hz 烘焙为 3.5 秒动画；预览触球事件 1.85 秒（第 111 帧）。Three.js BVHLoader 读取源数据，Blender 按源关节方向、根位移和肩胯朝向重定向；上下臂、大小腿保持现有固定长度。源 r/l 分别对应现有视觉 rig 的 L/R，源右脚踢球对应视觉 `foot.L`。源骨架为 Y 向上，Blender 为 Z 向上，GLB 导出恢复 Three.js Y 向上。

现有 22 骨映射涵盖 pelvis/spine/chest/neck/head、clavicle/upper_arm/forearm/hand、thigh/shin/foot/toe。手指合并在现有手部骨骼上。骨盆、肩膀与四肢主体使用采集数据；脚底使用实际鞋网格最低点校正，支撑脚在 1.65–2.55 秒锁定、前后平滑过渡，腿部 IK 修正长度。鞋尖对齐球的接触表面。头颈当前随胸部朝向，独立视线和手指动作待后续处理。

## 资源和性能

- 17,518 三角面、22 骨、6 材质、6 primitives、两张 512/128 贴图，与此前模型相同。
- GLB 407,288 字节（397.7 KiB），此前 372,056 字节；增加约 9.5%，主要来自真实采集的动画变化。单模型预算调整为 450,000 字节，面数和材质预算沿用此前设置。
- BVH 留在制作目录；页面只请求所选 GLB 和对照 GLB。原始 120 Hz BVH 不进入动画运行循环。
- 本机 macOS、Codex 内置 Chromium 浏览器、无阴影、同屏双角色短时播放：697×784，DPR 2、渲染比 1.70，帧间隔 P50/P95 16.7/16.8 ms；390×844 模拟视口，DPR/渲染比 1，16.7/16.9 ms。两次观察均无 >33 ms 帧。
- 示例动画更新 0–0.1 ms，20 calls（触球帧）、36,086 triangles（含场景和对照）。本地资源请求 46.7–73.5 ms、解码 6.9–8.7 ms；这属于开发服务器观测，不能作为公网冷启动下载指标。

- 全部 128 项 Node 测试通过，含新增动捕长度/连续性/触球/穿地/支撑脚与预算检查。

- 浏览器检查正面、侧面、助跑、触球、随摆和恢复姿态，操作正常速度和四分之一速度；检查 390×844、844×390 布局。竖屏镜头已扩大以容纳动捕侧向助跑；横屏播放按钮优先显示。

## 待验收

当前为单一常规射门的视觉原型，片段结束仍处于恢复步，尚未接回循环待机。方向、力度和球路选项仍控制原物理预演，动作本身使用同一动捕片段；不同射门类型、左右镜像、中断混合、门将和正式比赛接入等待本原型视觉确认。完整连续录像人工审片、极端姿态穿模、长时间运行与反复加载内存趋势，以及手机真机发热/降频/30–60 fps 目标仍待验证。

## 待机手臂与手腕修正

待机 0–0.35 秒使用轻微屈肘、自然下垂的双臂，手腕低于骨盆；0.35–0.95 秒通过五次平滑曲线衔接源动捕，之后保留采集的上下臂方向。去掉此前从 Daz 合成 `Mid1` 指关节推算手腕朝向的做法，手部沿前臂自然延伸并保留轻微松弛屈曲。固定手部网格仍保留原有手指形状。

新增回归检查覆盖待机上臂接近竖直、手腕高度、全片手腕与前臂夹角和相邻帧旋转连续性。触球事件、支撑脚和下肢数据保持原值。浏览器已检查待机、过渡中段和摆腿时的正面/侧面姿态。
